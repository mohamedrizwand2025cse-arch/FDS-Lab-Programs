# FDS Lab — Questions and Answers

This repository contains a combined Markdown document for the **Fundamentals of Data Science Lab (CS23334)** experiments. Each experiment section places the question/aim/description together with the corresponding code and output text available in the uploaded manual.

## File

- `FDS_Questions_and_Answers.md` — combined experiment questions and answers.

## Notes

- Some manual experiments refer to external CSV files such as `sales_data.csv`, `diabetes.csv`, `website_traffic.csv`, `Iris_Dataset.csv`, `employee.csv`, `50_Startups.csv`, `Hotel.csv`, and `Mall_Customers.csv`. Those data files are not included unless added separately.
- Notebook output and code extraction can be incomplete where the source manual uses screenshots or contains blank pages. Check the original lab manual before submission.
- Install the required Python libraries for the experiment you run, for example: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`, `scipy`, `statsmodels`, `nltk`, and `cryptography`.
